### Gotchas worth remembering
- Folder name `Coach` has capitals → `create-next-app` refuses. Scaffold into a
  lowercase temp dir and move up.
- `npm i prisma` resolves to an 8.0 release candidate that mismatches the 7.x
  client. Pin `prisma@^6 @prisma/client@^6`.
- Prisma + SQLite does not support `skipDuplicates` on `createMany`.
- Zod v4: avoid `z.string().email()`, use a regex.
- A CSS animation whose final keyframe keeps `transform` turns the element into
  the containing block for `position: fixed` children — modals must be portalled
  to `document.body`.
- Chunks overlap by design; stitch them back with `mergeOverlappingChunks` before
  displaying or summarising a whole document.
- Lexical retrieval needs a *relative* cutoff (score vs best match), not a fixed
  absolute threshold, or long chunks never clear the bar.

## Iteration 2 — quizzes, planner, progress, recommendations (same day)

All nine features from the brief are now implemented.

- Quiz generation lives in `src/lib/ai/quiz.ts`: Gemini JSON path with validation,
  plus an offline extractive generator (definition questions first, cloze to fill).
- Correct answers are never sent to the client before submission.
- Missed topics create Recommendations; correct answers close them.
- Planner spreads N sessions evenly across a date range and can focus on weak topics.
- Progress page derives everything from QuizAttempt + StudyActivity rows.

### Lessons from tuning the offline quiz generator
- A naive "X is Y" regex produces nonsense ("The fix is to move CourseTitle…").
  A definition must open with a determiner (a/an/the/any…) and the term must not
  be a generic noun; otherwise fall back to cloze.
- Cloze needs the surface form of a token ("StudentID", not "Studentid") and must
  skip sentences where the term occurs twice.
- Singularise the last word of a term for dedupe ("dependency"/"dependencies").
- Quality bar: it is better to emit fewer, sensible questions than five silly ones.

### Bug fixed
`Math.round(minutes/60)` plus `minutes % 60` rendered 105 minutes as "2h 45m".
Use `Math.floor` for the hour component.
